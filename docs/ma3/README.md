# Documentation de référence grandMA3

Claude Code lit ce dossier pour éviter d'inventer des commandes ou des fonctions Lua.
Dépose ici (en .md ou .txt) :

- `commandes.md` : syntaxe des mots-clés utilisés (Store, Label, Assign, Set, Export, Delete, ChangeDestination, Plugin…), copiée du manuel grandMA3 de ta version.
- `lua-api.md` : fonctions de l'API Lua que tu as vérifiées (Printf, DataPool, Root, Children, Dump, Cmd…), avec leur signature.
- `xml-exemples/` : quelques exports XML réels (macro, preset, sequence, matricks) pour que Claude connaisse leur structure.
- `version.md` : la version exacte de grandMA3 onPC utilisée.

Ce qui a été vérifié sur la console doit être noté comme tel ; le reste est à considérer comme une hypothèse.
